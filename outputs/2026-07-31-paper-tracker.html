LLM-Memory
Understanding Is Done Early: A Depth Division of Labor in Large Language Models and Its Use for Unbounded-Context Memory (CoMem)
Hanzuo Liu, Xuan Qi, Chunyu Liu, Haotian Zhong, Yulong Wang, Rayying Key, Alex Lamb, Mingyu Gao · arXiv cs.CL, 2026-07-30 LLM-MemoryKV-Networks

Approach: The authors exploit a depth division of labor in transformers — lower/middle layers build semantic representations while upper layers specialize them for prediction — and turn it into a memory system (CoMem). Each context chunk is cached only through an intermediate layer as a residual state; at query time a fixed number of cached states are retrieved and the query-conditioned upper layers are recomputed over the resulting pack, on a frozen Qwen3-8B with a rank-32 self-distillation LoRA trained on PG19.

Finding: CoMem reaches 97.05 on RULER and 38.27 on LoCoMo versus 34.59 for full-context KV-Direct, and at 128k context on an H20 uses 18.26 GB vs 89.36 GB with a 7.83× prefill speedup. The work shows long-context memory can be organized along the layer axis rather than only the token axis — a direct alternative to KV-cache retention for unbounded context, and a useful control for lingering-memory work that assumes token-axis KV retention is the mechanism of interference.

RRM: Experience-Driven Reflective Retrieval Memory for Long-Horizon Multimodal Reasoning
Jingxiang Fan, Junbao Zhuo, Bochao Zou · arXiv cs.CL, 2026-07-30 LLM-Memory

Approach: RRM augments an entity-centric multimodal memory graph with a "reflective experience memory" that distills transferable procedural retrieval knowledge from historical task trajectories, converting retrieved experiences into query-level guidance for future search. A lifecycle manager regulates experience memory via usage frequency, reuse feedback, and temporal decay to curb redundancy and noise.

Finding: RRM consistently outperforms prior state-of-the-art on M3-Bench-Robot, M3-Bench-Web, and Video-MME-Long for long-horizon multimodal reasoning. It cleanly separates reusable search strategies (across tasks) from the factual episodic/semantic evidence stored per video — a meta-memory layer on top of ordinary memory retrieval, conceptually adjacent to the lingering-memory question of what an agent should keep versus how it should search.

CACHE-UK: A Stability-Aware Memory Editor for Sequentially Updated Quantized LLMs in Finance
Anubhav Lakra, Yue Feng · arXiv cs.CL, 2026-07-30 LLM-Memory

Approach: Targeting the "quantization stability crisis" where 4-bit LLMs degrade under sequential memory edits, CACHE-UK confines edits to a rank-1 LoRA perturbation subspace, adds a financial-domain prioritization module for content-adaptive edit strength, and closes the loop with a Stability Controller that tracks "degradation debt" to prevent catastrophic forgetting across updates. Evaluated on a 4-bit quantized OpenLLaMA-3B over a curated 88,021-document UK financial corpus.

Finding: CACHE-UK reduces sequential knowledge degradation by 11–17% relative to adapted baselines and reaches the highest test success rate in the setting (28%, a 6-percentage-point gain over the strongest baseline). Absolute generalization remains low (28%), so the effect is robust but modest in scale — relevant to safe sequential memory editing/updating in resource-constrained LLMs, i.e. the forgetting half of the lingering-memory/continual-update problem.

A hierarchical coordinate system for sequence memory in human entorhinal cortex
Shpektor, Bakermans, Baram, Sarnthein, Ledergerber, Imbach, Barron, Behrens · bioRxiv (2024) / eLife Reviewed Preprint, posted 2026-07-30 Schema-Episodic

Approach: The authors test whether the rodent entorhinal grid-cell coordinate system generalizes beyond 2D space to arbitrary sequences. In human MTL single-unit recordings during a simple sequential memory task they looked for abstract coordinate-like coding; in an fMRI experiment with complex hierarchical sequences they tested for an abstract hierarchical entorhinal representation arranged on an anatomical gradient.

Finding: They find abstract, coordinate-like coding of the sequential memory task in human MTL single units, and an abstract hierarchical representation in EC whose coordinate levels are arranged along the anterior–posterior axis — homologous to the rodent ventro-dorsal grid gradient. The result suggests memories are scaffolded on a hierarchical coordinate system using conserved neuronal coding principles across domains and species; directly actionable for schema/scaffold models of episodic memory and the Pillar-2 prior-knowledge binding question. (Originally a 2024 bioRxiv preprint, newly posted as an eLife Reviewed Preprint 30 Jul 2026.)

Excitatory cholecystokinin neurons in the CA3 area regulate navigation learning and neuroplasticity
Fengwen Huang, Abdul Baset, Stephen Temitayo Bello (City University of Hong Kong) · eLife, Version of Record 2026-07-28 Schema-Episodic

Approach: In adult mice the authors characterize excitatory cholecystokinin (Cck) neurons in CA3 that project to CA1, combining retrograde labeling, optogenetic/chemogenetic pathway perturbation, hippocampal-dependent behavioral tasks (novel-object location, Morris water maze), and in-vitro LTP. ~8.50% of CA1 neurons and 20.34% of CA3 neurons are Cck-positive; 90.15 ± 15% of CA1-projecting CA3 neurons are excitatory Cck+.

Finding: CA3 Cck→CA1 projections are necessary for spatial learning and neuroplasticity: chemogenetic inhibition raised Morris water-maze day-5 escape latency (24.2 ± 4.4 vs 15.1 ± 2.1 s, p=0.003) and cut target-quadrant occupancy (27.9 ± 2.8 vs 42.3 ± 3.8%, p=0.02), and attenuated LTP (post-TBS slope 111.5 vs 125.2%, p=0.005). This is the first demonstration that excitatory (not inhibitory) hippocampal Cck neurons gate CA3→CA1-dependent memory and plasticity — a modulatory substrate for schema-guided hippocampal function. NIH/n-values are modest mouse cohorts; effects are consistent and replicated across inhibition and knockdown.

KV-Networks
Stage-Replay Divergence Follows the KV Cache: Fixed-Prefix Precision Controls and Bidirectional Cache Transplantation
Alexander Boesgaard Lorup · arXiv cs.LG/cs.CL, 2026-07-30 KV-Networks

Approach: The author audits the stage-replay assumption — that fresh-prefill of identical tokens reconstructs the live-decoder state at a reasoning-stage boundary — in a Qwen2.5-derived system, using a matched 200-item experiment crossing retained live cache vs one-shot prefill, a fixed-prefix 2×2 holding all 200 token states constant while varying construction and precision, and bidirectional transplantation of all 48 K/V layers.

Finding: In BF16, reconstructions disagree on 166/200 suffixes and 20 correctness labels but accuracy differs by only one point (paired 95% CI [−3.5, +5.5]); FP32 yields no decoded disagreement (Wilson 95% upper bound 1.88%). Transplanting all 48 K/V layers makes every divergent continuation follow its cache donor (24/24 at the primary checkpoint, 43/43 in a blind replication), establishing boundary K/V cache as a causally sufficient carrier of the divergent trajectory, with numerical precision moderating its behavioral expression. A crisp mechanistic probe relevant to Pillar 3's claim that KV states encode position/event memory.

ReToken: One Token to Improve Vision-Language Models for Visual Retrieval
Yao Xiao, Reuben Tan, Zhen Zhu, Yuqun Wu, Jianfeng Gao, Derek Hoiem · arXiv cs.CV/cs.LG, 2026-07-30 KV-Networks

Approach: ReToken trains a single learnable embedding as an explicit retrieval target that selects a sparse set of query-relevant visual tokens from a pre-filled visual KV cache, addressing distractor growth and GPU-memory limits in long visual context for VLMs. It is trained only on a small image-QA dataset and slots into existing VLMs without architectural change.

Finding: On Visual Haystacks it improves Qwen3VL-8B by 13.4 points and InternVL3.5 by 12.4 points (>20% relative), and transfers zero-shot to long video on LVBench for an 8.0-point gain with Qwen3VL-8B. The result shows a one-token "retrieval head" over a pre-filled KV cache can recover in-window visual tokens efficiently — a concrete demonstration of query-conditioned KV selection that parallels the position/format-preference confound in lingering-memory experiments.
