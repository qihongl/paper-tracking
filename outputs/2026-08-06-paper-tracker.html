LLM-Memory
Caching for the Future: Scrub Jay Episodic Memory Principles for Agent Memory Systems
Bhandari, Wadhwani, Kumar, Narang · arXiv, 2026-08-05 (v1) LLM-Memory

Approach: Operationalizes the western scrub jay's type-conditioned temporal decay as a per-memory auto-classified perishability coefficient π_i in an external LLM-agent memory store. Each memory is a jointly-bound What–Where–When tuple with an estimated perishability and utility horizon τ_i, retrieved by query-adaptive scoring and revised retroactively at O(1) LLM calls. Evaluated with a new Temporal Generalization Test (TGT) using held-out retention intervals and a Generalization Gap (GenGap) metric, plus MemoryAgentBench EventQA-64k.

Finding: On TGT, ScrubJay-MEM is the only retrieval-based system with substantially positive GenGap (+0.108); on EventQA-64k it improves F1 by +2.66 over Mem0 and +3.09 over Qwen3-Embedding-4B. A decay ablation collapses GenGap by 5.7×, establishing type-conditioned decay as necessary. Directly relevant to Pillar 1: explicit, mechanism-grounded (perishable-fact) temporal memory rather than uniform persistence.

Gains narrow under stronger backbones and reverse on fact-consolidation tasks — contribution scoped to temporal reasoning over perishable facts.
Hierarchical Graph Memory for LLM Agents with Path-level Localization and Rewrite
Yue, Wang, Zhang, Zheng, Ziwei Zhang · arXiv, 2026-08-05 (v1) LLM-Memory

Approach: Proposes an evolving hierarchical graph memory (coarse-to-fine upper-level nodes + MemoryUnits) to reduce irrelevant context during retrieval, plus MicroGraph-based path-level localization that identifies the support subgraph and evidence path before rewrite, and a coordinated rewriting method that jointly revises intra-unit memory and inter-unit dependencies. Tested on long-term conversational QA and conflict-aware memory benchmarks.

Finding: Substantial improvements over flat-graph baselines in answer quality and token efficiency, with better accuracy and query-valid evidence selection under dynamic, static, and conditional conflicts. Relevant to Pillar 1 as a structured, update-efficient long-horizon memory organization — structured state as the active ingredient (cf. SLEUTH).

ContextWeave: A Real-World Workflow Benchmark
Wang, Yao, … Qiu · arXiv, 2026-08-05 (v1) LLM-Memory

Approach: A longitudinal benchmark reconstructing privacy-preserved, multi-month workflows of 14 participants into 1,005 executable tasks (568 core evaluation), with instructions, containerized environments, trajectories, and rubrics. Measures workspace quality and alignment with participant-specific preferences, plus diagnostics of relevance, continuity, solvability, and robustness to misleading recall.

Finding: Across six memory components under a fixed model, the strongest configuration raises Workspace Score 68.08→78.20 and Preference Score 41.50→70.60; with a fixed memory component, recall improves outcomes for all five tested base models, though gains vary. Findings motivate memory systems that optimize reliable use during execution, not just retrieval relevance. On-pillar Pillar 1 as an evaluation harness for experience-rich agent memory.

Schema-Episodic
Hippocampal CA3 connectomics reveals a gradient of mossy fiber inputs and selective feedforward inhibition onto pyramidal cells
Zheng, Park, … Tank · Nature Neuroscience, 2026-08-05 Schema-Episodic

Approach: Assembled a ~1×1×0.1 mm³ 3D electron-microscopy volume from mouse hippocampal CA3 and reconstructed all soma-containing neurons (1,815 pyramidal, 229 inhibitory) and >55,000 mossy-fiber (MF) axons via proofread automated segmentation.

Finding: Pyramidal cells receive more numerous MF inputs along a proximodistal gradient (some distal cells showing high convergence via small terminals); pyramidal cells share more MF inputs than randomized networks. The authors identify a feedforward inhibitory motif from MFs via perisomatic interneurons that selectively targets a pyramidal subtype. Large-scale circuit-to-cell-type mapping of CA3 — directly on-pillar Pillar 2 (CA3/place cells, mossy-fiber input statistics, inhibitory control of recall).

Creating true and false memories from forgotten information in Drosophila
Yang, Zattera, … Felsenberg · Nature Neuroscience, 2026 Schema-Episodic

Approach: Used Drosophila to test how forgotten aversive memories are recovered by reminder cues and how recovery can be distorted into false memories; combined behavior with neuronal tracking of mushroom-body output neurons across reminder conditions.

Finding: Forgotten memories persist as silent traces in behaviorally neutral mushroom-body output neurons; reminders recover true memory by reinstating the original trace, while manipulated reminders create false memories. Both true recovery and false formation are context-dependent and gated by separable dopaminergic pathways — forgotten memories re-emerge through a reconstructive process integrating stored and recent information. On-pillar Pillar 2: memory traces, reconstructive retrieval, false-memory formation.

Subicular plateaus signal reward locations during goal-directed behavior
Bhatia, Adel, Grienberger · Cell Reports, 2026-08-05 Schema-Episodic

Approach: In vivo whole-cell recordings from dorsal subiculum neurons in head-fixed mice performing goal-directed navigation; examined burst origin (plateau events), NMDA-dependence, and organization by pre-onset membrane potential.

Finding: Many subicular bursts arise from plateau events (NMDA-dependent). Plateaus initiated from hyperpolarized potentials clustered near reward locations and required a fixed learned reward location, dynamically rearranging when a new reward location was learned in a familiar environment; depolarized-initiated plateaus were more spatially distributed. Identifies subicular plateaus as a cellular substrate of hippocampal output bursting organized by behavioral state — on-pillar Pillar 2 (hippocampal output, reward coding).

Integrated decoding of local and prospective spatial representations for future decision prediction
Wang, Luo, Wang, Deng, Zheng · Journal of Neural Engineering, 2026-08-03 Schema-Episodic

Approach: Recorded hippocampal CA1 ensemble activity from rats in a continuous spatial decision task on a modified T-maze; segmented the decision process into starting/running/approaching phases and examined local (place-cell) and prospective (choice-arm) representations over time.

Finding: Central-arm place cells showed increasing trajectory-dependence near the choice point (local theta sequences overrepresenting the actual choice), while prospective representations transitioned from predicting the actual choice during running to representing potential paths more equally near the choice point. Integrating local + prospective features reached 74.4% future-choice accuracy and 78.2% trajectory decoding. On-pillar Pillar 2 (CA1 cognitive map, prospective coding).

KV-Networks
When Does Latent Communication Pay? A Causal Audit of Relayed KV Caches in Multi-Agent LLMs
Cheng, Das, Ramnath · arXiv, 2026-08-05 (v1) KV-Networks Cross-cutting

Approach: Causally audits the claim that multi-agent LLM systems gain from relaying KV caches (vs text) by replacing the relayed cache with deranged (mismatched-example), zeroed, and moment-matched random counterparts, under two regimes (receiver needs vs does not need the sender's private info). Uses a pre-registered five-seed TOST with Holm correction on GSM8K/ARC-Challenge/MedQA across Qwen3 scales.

Finding: Where the receiver needs private info, a mismatched cache reads ceiling (100% vs 23–25% for answer-irrelevant relays); where it does not, equivalence within 2.8 points. A large cache effect need not be a pairing effect (zeroing costs 14.7 pts; a mismatched cache only 0.4). Establishes that benchmark deltas do not prove latent-thought transmission — a methodological corrective for treating KV caches as memory stores. On-pillar Pillar 3 (KV cache as memory; causal attribution of what the cache carries).

Boundary-constrained chunking shapes local-global positional representations in working memory
Yang, Wang, Zhan · Memory, 2026-08-04 KV-Networks Encoding-Retrieval 📚 matches-library

Approach: Four behavioral experiments; participants encoded nine-item sequences (structured linguistic, scrambled linguistic, color-segmented shape, uniformly colored shape) and reported probed positions. Parameterized behavioral representational-similarity analysis on position-specific response distributions characterized local vs global positional geometry.

Finding: Structured linguistic sequences produced near-orthogonal local/global positional geometry (clearly separable); color-segmented shapes gave a reduced-angle/reduced-scale (weaker) solution with participant heterogeneity; scrambled/uniform sequences collapsed to 1-D (no separable local-global). Shows chunking does not yield a uniform WM format — separable positional structure depends on the source and strength of chunking cues. On-pillar Pillar 3 (serial/positional representations).

Encoding-Retrieval
Phase similarity between similar objects indicates representational merging across retrieval training but not sleep
Caldwell, Chatburn, Lushington, Hanslmayr, Michelmann · Imaging Neuroscience, 2026-07-31 Encoding-Retrieval 📚 matches-library

Approach: 30 subjects (27F, 18–34) learned object-word pairs, then immediate recognition, then one of four 120-min interventions (retrieval training, restudy, sleep, wake), then delayed recognition; compared EEG phase similarity between similar/different objects across encoding and each intervention.

Finding: Increased representational similarity between similar objects across encoding (theta, occipital). Crucially, additional merging occurred only across retrieval training (alpha, parieto-occipital), not sleep; greater merging across retrieval training predicted better similar-object-lure discrimination. Concludes sleep and retrieval training induce different memory transformations over equivalent timescales — retrieval training drives rapid gist extraction/neocortical integration; sleep selectively maintains task-relevant details. On-pillar Pillar 2/ER (consolidation, representational transformation).

Memory Traces Reflect How They Were Last Accessed
Qi, Coutanche · Journal of Cognitive Neuroscience, 2026-08-04 Encoding-Retrieval

Approach: fMRI; participants learned novel word-image pairs, then re-exposure requiring semantic access at item/category/theme levels, then recognition. Compared neural patterns by prior semantic-access level (early visual, ventral temporal, hippocampus) and tested whether same-level access yielded more similar/distinct representations.

Finding: Behavioral performance matched across conditions, but recognition patterns were classifiable by prior semantic-access history in early visual cortex, ventral temporal cortex, and hippocampus; category-level access increased similarity among items in early visual cortex, while item-level access produced more differentiated representations in the visual word form area. Shows semantic-access history during retrieval leaves measurable traces in subsequent neural representations.

Tuning out emotional distractors by tuning in theta rhythm: improving visual working memory using TMS
Thiffault, Brisson, Blanchette · Social Cognitive and Affective Neuroscience, 2026-08-04 Encoding-Retrieval

Approach: Rhythmic TMS (rhTMS) boosted theta power over left DLPFC in 19 healthy participants during a visual change-detection task with neutral/angry-prosody auditory distractors; EEG measured theta power, contralateral delay activity (maintenance), and auditory P2 (distractor processing).

Finding: rhTMS boosted theta power and improved vWM accuracy vs sham; the theta boost associated with lower emotional-distractor processing, not better maintenance. Indicates attentional control of emotional auditory distractors in vWM operates via inhibition of distractors rather than amplification of relevant items.

Cross-cutting
Reward Structure Shapes the Interaction Between Episodic Exploration and Neural Memory in Reinforcement Learning
Malegaonkar, Patil, Christensen · arXiv, 2026-08-05 (v1) Cross-cutting LLM-Memory

Approach: Controlled study crossing episodic exploration bonuses with diverse neural memory architectures across three POMDP environments that vary how memory content is acquired; uses observation-anchored reward machines to separate structural sparsity from potential sparsity.

Finding: An identical bonus yields three regimes — amplifies architectural capacity differences (unsupervised memory discovery), equalizes architectures to a shared ceiling (single reward-supervised cue), or is null (purely scheduled observations). Controlled reward manipulations verify patterns track reward structure, not density. Conclusion: exploration and memory are complements, not substitutes — a bonus induces exposure, only memory converts it to return. On-pillar Pillars 1 & 3 (episodic memory, neural memory architectures).
