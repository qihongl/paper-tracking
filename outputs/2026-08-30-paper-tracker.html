LLM-Memory
A complementary learning system for continual episodic memory in large language models
Xu Pan, Ely Hahami, Roy Siegelmann, Haim Sompolinsky (Sompolinsky) · bioRxiv, 2026-08-24 LLM-Memory Schema-Episodic

Approach: A pretrained LLM supplies the semantic (neocortical) context; a hippocampus-like fast module assigns each episode to a dedicated, extremely sparse low-rank adapter, and competitive gating selects among these separated traces at recall. An internal retrieval-augmented mechanism reconstructs the selected episode back into context for question answering. Slow "cortical" consolidation is implemented by fine-tuning the base weights through batch replay. Tested on streams of up to 1,000 factual and autobiographical episodes.

Finding: Each adapter costs only 2–3 parameters per token while preserving excellent recall at 1,000-episode scale; batch-replay consolidation then supports reconstruction and direct question answering without the episodic adapters. This is a rare implementation of both CLS components — fast separated storage plus slow integration — inside a single model, and it directly targets the interference-vs-consolidation trade-off that Hebbian superposition models (Hopfield-style, shared weights) get wrong.

⚠ Preprint, not peer-reviewed. "Excellent recall" is not quantified in the abstract — no accuracy figures or baselines given; the interference claim at 1,000 episodes needs the curve, not the adjective.
Does Episodic Memory Help Close the Lexical Frequency Gap in Sensitivity to Syntactic Contrasts? A Test Using Retrieval-Augmented Language Models
Jing Liu, Najoung Kim (Kim) · arXiv cs.CL, 2026-08-24 LLM-Memory

Approach: Draws on Complementary Learning Systems theory to predict that a hippocampal-style episodic store should make grammaticality judgements robust to lexical frequency. Episodic memory is instantiated as k-nearest-neighbour language models — explicit instance storage bolted onto a parametric model — and tested on syntactic contrasts with frequency-stratified items, across models pretrained on child-realistic and large-scale corpora.

Finding: Retrieval augmentation narrows the performance gap between high- and low-frequency items, consistently across syntactic phenomena and pretraining regimes. Critically, structural information drives effective retrieval while semantic similarity alone provides little benefit — a useful constraint on what an episodic store must index. The gap is narrowed, not closed, so episodic memory partially compensates for weak parametric representations rather than replacing them.

⚠ Authors are explicit that this is proof-of-concept; the gap survives augmentation, so only the weak form of the CLS prediction is supported.
Shortcut Before Circuit: Document Statistics Time In-Context Conflict Resolution
Yijun Liao, Fanwei Liang (Liang) · arXiv cs.CL, 2026-08-25 LLM-Memory KV-Networks

Approach: When a context asserts two values for one fact, a model must commit to a cue — recency, repetition, or position — but natural data rarely makes these disagree, so behaviour cannot reveal which one was used. They train 26M-parameter transformers on a synthetic language in which recency and rarity are exactly coextensive, then apply a minimal causal edit that inverts one cue while holding truth, token count and answer position fixed. 75 runs total.

Finding: Every run reaches accuracy ≥ 0.999, so no held-in evaluation distinguishes which cue was used. The per-cell attribution readout does not replicate: 13 of 25 cells differ by more than 0.3 in sign fraction across three seeds (largest 0.879 against a standard error of 0.025). What does replicate is timing — escape from a positional shortcut with a closed-form ceiling, monotone in redundancy — and probed before that escape, attribution reverses sign in 32 of 75 runs at unchanged accuracy. The claim is that corpus statistics determine when a mechanism appears, not which one, giving a criterion for when mechanistic attribution to data is available at all.

⚠ The replication failure rests on 3 seeds, and everything is done in a synthetic language at 26M parameters. This is a negative/methodological result; generality to real corpora is the open question.
Schema-Episodic
Prefrontal–thalamic goal states organize spatially aligned hippocampal maps
Zahra Golipour, Marjan Mozaffarilegha, Shao-Fan Yen, Cansu Üstüner, Hiroshi T. Ito (Ito) · Nature Communications, 2026-08-29 Schema-Episodic KV-Networks

Approach: Male rats navigated the same maze under different goal configurations while CA1, medial prefrontal cortex (mPFC) and nucleus reuniens (NR) were recorded. The design isolates the generalisation–separation problem: the hippocampus must maintain one stable spatial map while keeping individual experiences distinct. A causal arm silenced NR.

Finding: CA1 segregates navigation experiences by encoding goal state along a population dimension largely orthogonal to the spatial-coding subspace, so goal-configuration-specific maps remain spatially aligned. The same goal-state signal appears in mPFC and NR as persistent representations across both locomotion and immobility, reinstated when a previously experienced goal configuration recurs. Silencing NR reduces CA1 goal-state coding, shrinks goal-axis separation and removes goal-biased pre-navigation spike sequences — while leaving spatial coding intact. A clean dissociation between the "what for" and "where" subspaces, with a thalamic gate controlling the former.

⚠ Male rats only; sex-specific goal-coding strategies untested.
Dissociable effects of schema congruency on item recognition and source memory across levels of expectedness and surprise
Amnon Yacoby, Andrea Greve, Erin Schaverien, Limor Shtoots, Richard N. Henson, Daniel A. Levy (Levy) · Memory & Cognition, 2026-08-28 Schema-Episodic 📚 matches-library

Approach: Four experiments. Participants viewed scenes containing schema-congruent or incongruent objects and rated each on a four-level expected/surprising scale. Memory was probed two ways: old/new item recognition decomposed into recollection and familiarity, and source memory for whether the object had been rated expected or surprising. The SLIMM framework predicts a U-shaped function of expectedness.

Finding: The two tests dissociate. Item recognition shows an advantage for expected trials only, driven by recollection; familiarity instead increases with surprise, contrary to SLIMM. Source memory does produce the U-shape — but for a reason SLIMM does not predict: participants appear to tag events as "expected" or "surprising" at study and later retrieve the tag, falling back on schema-based retrieval only when the tag is weak or unavailable (i.e. for moderately categorised events). Prior knowledge therefore shapes episodic memory in a strongly test-dependent way.

Top library hit: Frank, O'Reilly & Curran (2018) on beneficial and detrimental effects of schema incongruence.
Neural Organization of Episodic Memory and Navigation in Children and Adults
Kim V. Nguyen, Lena J. Skalaban, Büşra Tanriverdi, Jack J. Erardi, G. Arantes de Oliveira Campos, Ingrid R. Olson, Vishnu P. Murty, Nora S. Newcombe (Newcombe) · Journal of Cognitive Neuroscience, August 2026 Schema-Episodic Encoding-Retrieval

Approach: Naturalistic encoding: children aged 8–13 and young adults first had real-world experiences (a tour of a new environment, or sitting in a room with objects) and later viewed pictures of those objects plus novel foils during fMRI. This contrasts episodic memory that is versus is not additionally embedded in a navigational experience — the key manipulation is that natural navigation requires moving one's body through space while episodic memory does not. Univariate activation plus functional connectivity.

Finding: Tour-related activity in entorhinal (ERC) and perirhinal (PRC) cortex differs between early adolescents and adults. ERC–PRC connectivity supporting episodic memory decreases with age — a counterintuitive developmental direction that argues against simple "integration increases with age" accounts. Exploratory analyses implicate hippocampus–ERC–lateral occipital connectivity in reconstructing spatial context. Both episodic and navigational contexts engage MTL, but the regions interact differently by context and developmental stage.

⚠ Connectivity results are explicitly exploratory; PubMed carries a date typo (2028-08-17) on this record.
Naturalistic paradigm — relevant to the ongoing Sherlock / PIEMAN / ds005658 replication work.
Dopaminergic fronto-striatal connectivity underlies schema-dependent learning
Mushfa Yousuf, Niels Kloosterman, Jannik Prasuhn, Norbert Brüggemann, Lluís Fuentemilla, Nils Bunzeck (Bunzeck) · Journal of Psychopharmacology, 2026-08-25 Schema-Episodic

Approach: Double-blind mixed design in 90 healthy humans (70 female, 20 male): 1.25 mg bromocriptine (D2 agonist), 400 mg sulpiride (D2 antagonist), or placebo before encoding semantically congruent versus incongruent words during fMRI, with recognition tested the following day.

Finding: Semantic congruency enhanced next-day recognition in all three groups, but the size of the effect followed an inverted-U as a function of drug: the congruency effect was largest under placebo and significantly reduced by both the agonist and the antagonist. Neurally this was mirrored by non-linear modulation of striatal activity and its functional connectivity with the superior frontal gyrus. Schema-dependent learning is therefore dopamine-dependent in a non-monotonic way — both too little and too much D2 tone degrade it, which is a sharper prediction than any simple "dopamine helps" account.

⚠ Sample is 78% female and sex was not modelled; no plasma drug levels, so the inverted-U is inferred from dose rather than exposure.

Organizational Dynamics of Memory Across Days
Daniella A. Rafla, Nathaniel R. Greene, Bradley S. Katerman, Dana Halpern, Michael J. Kahana (Kahana) · Journal of Experimental Psychology: Learning, Memory, and Cognition, 2026-08-27 KV-Networks 📚 matches-library

Approach: Classic studies tracked how recall organisation evolves across lists within a single session. Here two multi-session free-recall experiments ask how semantic, temporal and subjective organisation during one recall period shapes memory after days of intervening cognitive activity — a timescale nobody has tracked organisation over.

Finding: Subjects show a strong tendency to cluster recalls according to previous output order, and this effect strengthens across sessions — recall organisation is itself a learned, persisting structure rather than a transient readout of the study list. Consistent with "thoughts become memories," even false memories produced in one session tend to re-occur on subsequent days. This is a direct argument that retrieval, not just encoding, sculpts long-term episodic memory, and it is exactly the multi-timescale clustering behaviour that a temporal-context / CMR-style model should be able to reproduce.

Top library hit: Polyn, Norman & Kahana (2009), "A context maintenance and retrieval model of organizational processes in free recall" — the CMR paper.
TwinKV: A Composable Repair Pass for KV Cache Eviction via Pairwise Key Redundancy
Hong Chen, Yudong Zeng, Yongwei Huang, Zuhao Ouyang, Junyan Zhang, Xuming Hu (Hu) · arXiv cs.CL, 2026-08-27 KV-Networks LLM-Memory

Approach: A controlled leave-one-out probe measures each token's actual causal contribution to the answer, which is then compared against the attention weight used by dominant eviction policies. On that basis they build TwinKV: a training-free, attention-free redundancy signal detecting whether a token's key has a near-duplicate elsewhere in context. It operates as a composable repair pass — given a policy's fixed retained set, swap evicted "orphans" (no surviving duplicate) for retained "redundant donors," holding budget and scoring rule fixed. Composed with four recent policies across LongBench, LooGLE, RULER and an MMLU-Pro no-harm control at compression ratios {0.3, 0.5, 0.7}.

Finding: The headline is a negative result with teeth: attention magnitude is unrelated to a token's causal contribution to the answer (Spearman ρ = −0.004), undercutting the premise behind attention-scored eviction. TwinKV then improves a majority of configurations for two policies on Qwen3-4B, is near-even for a third, and helps only a minority of a fourth adaptive baseline already at ceiling — but on RULER with Llama-3.2-1B that fourth policy improves in every evaluated cell. It fails on few-shot classification exemplars on both models.

⚠ Preprint. Gains are strongly policy- and model-dependent; the repair pass only helps where the base policy left headroom, so it is not a free lunch.
Trust the Mass: Forced Weights in KV-Cache Eviction
Jack Shi, Jerry Gu (Gu) · arXiv cs.LG, 2026-08-25 KV-Networks LLM-Memory

Approach: Every deployed sparse-attention or KV-eviction rule keeps a subset of keys, discards the rest, and renormalises attention over the kept set. They enumerate the exact optimal subset under that constraint on 168,192 attention rows from five models — a brute-force upper bound on what selection can buy — and then measure the bytes each method actually holds in a shared evaluation pipeline.

Finding: Keeping the largest weights is already near-optimal: the exact best subset closes only a median 2–5% of the remaining gap to full attention. So published margins between eviction methods cannot come from selection quality. The margin comes from bytes: the strongest query-agnostic methods hold the full cache because per-head selections are stored as masks, and only ragged per-head storage frees that memory. Enforcing a nominal budget on one fixed selection costs 14–62 benchmark points, and an 87.6-point retrieval margin traces to rankings computed while the question was visible. Their ContourKV allocator wins 93 of 160 paired comparisons against that state of the art.

⚠ Preprint. The "question is visible" leakage critique applies to the specific baselines re-evaluated here; whether it generalises to all reported eviction margins is not established.
Encoding-Retrieval
Theta oscillations tag episodic memories for sleep-dependent consolidation
Dan Denis, Zhiyi Chen, Manroop Kaur, Bethany Clayden, Thomas Schreiner, Scott A. Cairney (Cairney) · PLOS Biology, August 2026 Encoding-Retrieval 📚 matches-library

Approach: Neurobiological frameworks have long proposed that some memories are "tagged" at learning for later consolidation, but direct human evidence has been missing. They used multivariate classification of human EEG to decode brain states at learning for memories that were subsequently consolidated across sleep versus across wakefulness.

Finding: Tagging states were decodable above chance. Tagging for consolidation across sleep — but not across wakefulness — was linked to 3–8 Hz theta activity during learning. The magnitude of this tagging-related theta response predicted slow-oscillation–spindle coupling during post-learning sleep (an established correlate of sleep-dependent processing), and that coupling in turn was associated with better memory at the post-sleep test. This closes a long-postulated chain in humans: theta at encoding → SO–spindle coupling in sleep → retention.

Top library hit: Diekelmann & Born (2010), "The memory function of sleep" — the sleep-consolidation classic.
Large-scale brain network reinstatement supports recognition memory
Jintao Sheng, Junle Li, Xiangli Zeng, Jinhui Wang (Wang) · PNAS, 2026-08-26 Encoding-Retrieval Peripheral

Approach: Rather than reinstatement of local activation patterns, they build dynamic large-scale brain networks from trial-wise activation maps in the Natural Scenes Dataset and test whether network-level (edge-based) item-specific representations exist and predict recognition.

Finding: Robust network-level item-specific representations at whole-brain, subsystem and regional scales. Network reinstatement — especially connections involving higher-order visual and dorsal attention systems — was associated with condition-level recognition performance and predicted item-level accuracy. It also mediated the relationship between local activation-based representations and accuracy, yet the two representational forms had distinct spatial topographies and contributed independently. Network-level reinstatement is therefore a partly separate coding channel, not a restatement of regional activity.

⚠ The alignment of network patterns with neuromodulatory receptor distributions and mitochondrial bioenergetic gradients is post-hoc and correlational — no independent prediction was tested.
Natural Scenes Dataset — large-scale naturalistic fMRI, relevant to the replication project.
A Single Dimension of Memory Strength Underlies Semantic and Phonological False Memories
Lyulei Zhang, Adam F. Osth (Osth) · Psychological Science, 2026-08-25 Encoding-Retrieval KV-Networks

Approach: The Deese–Roediger–McDermott paradigm produces false memory from either semantic or phonological similarity. Because semantic associates elicit more false "remember" (R) judgments while phonological associates elicit more false "know" (K) judgments, the two have been argued to reflect distinct memory processes. They tested this directly with semantic and phonological DRM tasks using old-new recognition followed by RK ratings (N = 227).

Finding: The R/K dissociation replicated, but both parametric and nonparametric analyses revealed a single underlying dimension: a signal-detection model in which R judgments reflect a stricter response criterion than K fitted the data nearly perfectly, and a state-trace analysis showed a monotonic relation between old/new and R false alarms across tasks. Semantic materials simply produce higher rates of false recognition — no separate process is needed. A clean case where a qualitative dissociation is fully explained by criterion placement on one strength axis.

Cross-cutting
Granule cells reorient cortical trajectories to separate contexts
Martha G. Garcia-Garcia, Michał J. Wójcik, Suhasa Thota, Lillian Drake, Amanda Otchere, Oluwatosin Akinwale, Lilian Ramos, Rui Ponte Costa, Mark J. Wagner (Wagner) · Nature, 2026-08-26 Cross-cutting Schema-Episodic

Approach: The textbook story is that generalisation rides on low-dimensional cortical manifolds while context separation requires an expanded, high-dimensional representation — cerebellar granule cells being the canonical expansion layer. They tested this directly by simultaneously imaging both ends of the cortico-cerebellar pathway, premotor layer-5 pyramidal tract (L5PT) neurons and granule cells, in mice learning two distinct skills that share a temporal structure.

Finding: Granule cells do not expand the cortical code: they retain a low-rank encoding of each task. Across contexts, cortico-cerebellar coupling stays stable and L5PT activity patterns generalise, whereas granule-cell patterns temporally remap — but coherently, with their low-dimensional trajectories rotating apart rather than scrambling independently. This separates contexts while preserving each task's cortical geometry, and the divergence is strongest in expert mice. The architectural claim: cortex supplies invariant dynamic primitives for smooth generalisation; cerebellum reconfigures them into context-specific output.

Film Recall Reveals Intact Event Memory but Impaired Sequence Memory in Temporal Lobe Epilepsy Patients
Forouzan Farahani, Herui Zhang, Eden Tefera, … Anli Liu (Liu) · Neuropsychologia, 2026-08-26 Peripheral KV-Networks

Approach: Naturalistic paradigm with high ecological validity: 51 participants (27 temporal lobe epilepsy, 24 healthy controls) watched six short films and then freely recalled them. Spoken responses were transcribed, segmented and scored at film, coarse-event and fine-event levels. Recall order was quantified with Damerau-Levenshtein distance, and semantic and causal centrality were estimated from sentence embeddings and rater-identified causal links.

Finding: The groups were indistinguishable on film-level (HC 89% vs TLE 88%, p = 0.54), coarse-event (50% vs 44%, p = 0.19) and fine-event (25% vs 22%, p = 0.17) recall; both recalled causally central events better. But TLE patients showed significantly greater fine-grained sequence deviations at recall (HC 15% vs TLE 23%, p = 0.02, Hedges' g = 0.85, Cliff's δ = 0.51), with right TLE worse still (29% vs 15%, p = 0.021). Age, education, MoCA and standard verbal/visual memory tests were all unrelated to film, event and sequence recall — so the task measures something the standard battery misses.

⚠ Exploratory, cross-sectional, single Level-4 centre; MoCA thresholds differed by group by design (TLE ≥ 22, HC ≥ 26), so general cognitive level is not matched.
Naturalistic paradigm — directly relevant to the ongoing Sherlock / PIEMAN / ds005658 replication work.
