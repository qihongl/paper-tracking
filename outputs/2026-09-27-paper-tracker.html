LLM-Memory
Memory Attention
Jiale Kang (solo author; no affiliation listed) · arXiv (cs.LG), 23 Sep 2026 LLM-Memory KV-Networks

Approach: Asks whether the value projection in attention is necessary at all. The proposed Memory Attention (MA) builds values from layer-specific, token-indexed memory tables combined with contextual keys — memory supplies the token-specific content, keys preserve context dependence. At inference, normalisation folds into the memory tables, so value construction reduces to lookup and addition, and the tables can be offloaded to CPU with prefetching.

Finding: Under matched training-token budgets (with extra memory parameters), MA improves language modelling loss and average downstream performance across attention configurations. The mechanism-level claim is the interesting part: a key-indexed content store can substitute for a learned value projection, which is exactly the K/V factorisation the KV-network pillar assumes.

⚠ Preprint, single author, no peer review; scale and architecture sweep not stated in the abstract — treat the claim as provisional
Transformer Mechanisms Mimic Frontostriatal Gating Operations When Trained on Human Working Memory Tasks
Soni, Traylor, Merullo, Frank, Pavlick (Brown University) · Journal of Cognitive Neuroscience, 21 Sep 2026 LLM-Memory Cross-cutting

Approach: Frontostriatal models attribute WM capacity limits to "role addressability" — binding items to roles and credit-assigning the gating operations that read and write them. The authors train Transformers (no built-in gating) on human WM tasks explicitly designed to tax gating, then dissect the mechanisms that emerge, comparing against frontostriatal predictions.

Finding: Attention does develop role-addressable input and output gating — but only when the training distribution rewards frontostriatal-like gating. Where it emerges, it improves generalisation and variable binding and increases the effective number of items the model can store and address. Gating looks like a computational attractor that any architecture converges on when the task demands it, not a biological accident.

⚠ Michael Frank is a co-author on this and on the Neuron paper below — both are directly on-pillar, read them together
Complementary Roles of Activation and Parametric Memory in Few-Shot Learning
Niu, Zhao, Liu, Jin, Qiao, Zhang, Zhu, Xiao (Northeastern University, China) · arXiv (cs.CL), 23 Sep 2026 LLM-Memory

Approach: Controlled dissociation of the two ways an LLM can carry history at test time: activation memory (the KV cache) versus parametric memory (updated weights). They test factual recall and task learning separately, then add a composite task, Conditional Arithmetic, that may require both, and run neuron-level analyses of which units are recruited under each regime.

Finding: Activation memory is superior for factual recall; parametric memory does not consistently beat activation memory on task learning. Conditional Arithmetic requires both working together. Neuron-level analysis: accessing the same information through the two routes activates largely distinct neuron sets, and the combined condition recruits from both — the union is what solves the task.

⚠ Preprint, not peer reviewed; a clean dissociation but the composite task is synthetic and the generalisation beyond it is untested
Schema-Episodic
Hippocampal representations of alternative possibilities are flexibly generated to meet cognitive demands
Comrie, Monroe, Kahn, Denovellis, Joshi, Guidera, Krausz, Berke, Daw, Frank (UCSF) · Neuron, 25 Sep 2026 Schema-Episodic KV-Networks

Approach: Hippocampal ensemble recordings in rats navigating a complex patch-foraging environment with changing reward probabilities — a setting with many candidate alternatives. They looked for representations of alternative spatial locations both along paths ahead of and behind the animal and in distant, unvisited patches, and asked how those representations are modulated across successive trials.

Finding: The hippocampus represents multiple alternatives simultaneously, including distant patches. Critically, the modulation differs by kind: alternative paths are represented in proportion to their evolving relative value and predict the next decision, whereas distant alternatives dominate during value updating. Generation of alternatives is thus not a fixed sweep but is titrated to what the current computation needs — a value-keyed sampling of a state space, which is close to the KV-network picture.

Navigational strategy dictates hippocampal representation of space in an everyday memory task
Gobbo, Mitchell-Heggs, Duszkiewicz, Faillace, Tse, Garcia-Font, Hazon, Clarke, Spooner, Keshishian et al. (Dorothy Tse lab) · Nature Communications, 24 Sep 2026 Schema-Episodic

Approach: Two carefully matched naturalistic variants of the everyday memory task run in the same arena, one forcing egocentric and one allocentric coordinates. CA1 activity was imaged with miniature microscopes in male rats during both, and hippocampal activity was optogenetically inactivated during the navigational decision/planning phase.

Finding: The chosen reference frame changes what CA1 represents and what memory-based planning looks like. Inactivation during planning abolishes performance on the allocentric version but leaves the egocentric version intact — a clean causal dissociation showing non-local hippocampal representations are specifically required when the frame is allocentric.

⚠ Male rats only; the allocentric/egocentric contrast rests on the two task variants behaving as intended
Abstract representation in the hippocampus predicts spontaneously adopted structure-based behavioral strategy
Yuhan Jiang, Yaorui Liu, Xinyu Zhao (Tsinghua University) · bioRxiv (neuroscience), posted 25 Sep 2026 Schema-Episodic KV-Networks

Approach: A structured cue-guided navigation task in virtual reality with longitudinal two-photon CA1 calcium imaging across the full course of learning in mice. The task never explicitly requires latent-structure learning. At test, sensory information was made partially unavailable to reveal whether each animal falls back on structure-based inference. Computational modelling tested which objectives reproduce the observed geometry.

Finding: Most animals progressively converted their hippocampal map from sensory-oriented into cue-invariant representations of the reward sequence — spontaneously, without task pressure to do so. Whether that abstract map emerged predicted individual strategy adoption. The reward-sequence representations formed a latent-state map supporting a parsimonious Markov graph of future transitions; next-state prediction plus representational regularisation were the two objectives needed to reproduce it across architectures.

⚠ Preprint, not peer reviewed; the strategy prediction is correlational (map emergence → strategy), so causal direction is not established
Navigation strategies predict spatial memory and hippocampal recruitment
Patai, Stawarczyk, Herweg, Gomes, Zhang, Schulze-Bonhage, Kunz, Axmacher (Ruhr University Bochum / Freiburg) · Cell Reports, 25 Sep 2026 Schema-Episodic Cross-cutting

Approach: Virtual navigation in three groups: epilepsy patients with invasive electrophysiology, fMRI in young adults at genetic risk for Alzheimer's (APOE-ε4 carriers), and healthy controls. Trajectories were reduced to quantitative strategy metrics — straightness, deviation to boundary, and path overlap — and related to hippocampal BOLD and theta power.

Finding: Strategy use is idiosyncratic, varies within a participant across the experiment, and adapts in a group-dependent way. Hippocampal BOLD and theta power are generally inversely related, and hippocampal recruitment depends jointly on group and on strategy. The practical upshot: "hippocampal engagement" is not interpretable without measuring what strategy the subject is actually running.

⚠ Three heterogeneous cohorts with unequal and partly small n; cross-sectional, so the AD-risk inference is about compensation, not decline
KV-Networks
Bridging real-world summarization and laboratory-based memory recall
Angne, Mishra, Lin, Zhang · Journal of Experimental Psychology: General, 24 Sep 2026 KV-Networks Encoding-Retrieval

Approach: Turns machine-learning summarisation corpora into cognitive-science data: 45,220 human summaries drawn from three large datasets (news articles, autobiographical stories, Reddit posts), compared against an existing dataset of narrative memory recall. The question is whether a real-world, deliberately abstract generative task obeys the laws of laboratory recall.

Finding: It does. Summarisation shows primacy, recency and temporal contiguity effects — the canonical recall signature — despite operating at a higher level of abstraction. And the relation is symmetric: recall itself behaves like summarisation, prioritising central and important information. This is the strongest naturalistic validation of contiguity-based retrieval I have seen outside the lab, and it hands us a 45k-sample corpus for testing temporal-context models.

⚠ Corpus comparison across different datasets and participants rather than within-subject; abstraction level differs between conditions by construction
Spaced repetition and list-strength in recognition memory
Caplan & Guitard · Memory & Cognition, 26 Sep 2026 KV-Networks Encoding-Retrieval

Approach: Three experiments in the regime that robustly produces an inverted list-strength effect (long study time, massed repetition) to ask whether spaced repetition behaves the same way. Attentional subsetting theory predicts inversion whenever weak items can be disregarded on pure-strong lists.

Finding: Spaced repetition produces a null or upright list-strength effect — it is resilient to the inversion that massed repetition and long duration produce under equated conditions. The boundary condition is sharp and constrains both attentional subsetting theory and REM: whatever spacing does to an item's feature distribution, it is not the same as what extra study time does.

Spike-history gating of plateau potentials enables closed-loop rewriting of CA1 representations
Anno C. Kurth & Toshitake Asabuki (RIKEN Center for Brain Science) · bioRxiv (neuroscience), posted 21 Sep 2026 KV-Networks Schema-Episodic

Approach: A two-compartment spiking model of CA1 in which recent somatic spike history gates whether a behavioural-timescale-plasticity (BTSP) plateau can initiate — cells are sensitive to rising activity after relative silence, and refractory to further plasticity during sustained firing. The gate interacts with entorhinal input to form a feedback loop; the authors then reanalyse existing experimental data to test a model prediction.

Finding: Because existing representations bias where subsequent plateaus land, the loop produces gradual place-field drift, reward-associated over-representation, recovery of environment-specific representations after remapping, and cross-day reinstatement — from one gate. The predicted relationship (stronger residual activity biases subsequent plateaus toward previous field locations) is found in data reanalysis. The claim that what is stored determines where the next write lands is a genuinely closed-loop memory mechanism.

⚠ Model plus reanalysis of existing data; no new experiment, so the predicted relationship is confirmed but not prospectively tested
Encoding-Retrieval
Learning from mistakes: Objective and subjective error magnitudes predict the testing effect
Aike Shi & Xiaonan L. Liu · Psychonomic Bulletin & Review, 24 Sep 2026 Encoding-Retrieval KV-Networks

Approach: Two experiments using a colour-wheel paradigm so retrieval error can be measured on a continuous scale. Three error signals are separated: objective error (angular discrepancy), predicted error (pre-feedback estimate of inaccuracy), and perceived error (post-feedback estimate). A computational model (WRAP-E) assigns distinct strengthening roles to each across retrieval stages.

Finding: Larger objective error during practice predicted greater memory updating. Beyond that, predicted and perceived error each uniquely predicted updating — the metacognitive reading of an error contributes over and above its actual size. Errors are not a byproduct of failed recall but the learning signal itself, which reframes the testing effect as error-driven learning.

Medial temporal default mode network selectively encodes autobiographical visual imagery
Andrew J. Anderson, Adam Turnbull, Feng V. Lin (Vanderbilt / Rochester) · Science Advances, 23 Sep 2026 Encoding-Retrieval Schema-Episodic

Approach: Fifty participants imagined re-experiencing 20 natural scenarios during fMRI, cued only by generic text prompts. Beforehand they gave verbal descriptions of each scenario, from which Stable Diffusion generated personalised synthetic images; those were passed through an image-recognition network to obtain hidden-state representations. Representational similarity analysis tested whether MT-DMN carries that structure, controlling for semantic features derived from a large language model.

Finding: MT-DMN encoded the participant-specific representational geometry of the reconstructed images even after removing LLM-derived semantics. The effect was absent in other networks and absent during reading without active imagination — so it tracks visual reconstruction, not language or generic scene content. Methodologically this is the template for using generative models as personalised stimulus encoders.

⚠ Synthetic reconstructions are an approximation to what participants actually imagined; the LLM semantic control is only as good as the LLM's feature space
Slow Oscillations Modulate Overnight Brain Changes in Working Memory Function
Zhang, Chen, Mednick, Tambini (UC Riverside / UC Irvine) · Journal of Cognitive Neuroscience, 21 Sep 2026 Encoding-Retrieval

Approach: WM task during fMRI before and after sleep, with simultaneous EEG–fMRI through the first 2.5 hours of sleep, so slow-oscillation (SO) activity during NREM can be related directly to the overnight change in WM-related activation.

Finding: Overnight change took a specific form: reduced dorsal precuneus recruitment during encoding/maintenance and reduced frontal recruitment during retrieval, together with increased item-specific reinstatement in a sensory region. Stronger SO activity in premotor cortex and ventromedial PFC predicted larger overnight reductions, with a parallel multivoxel relationship in the ventral attention network. Sleep appears to trade top-down control for sharper sensory reinstatement.

⚠ No wake control condition described in the abstract, so circadian and time-of-day alternatives to a sleep-specific effect are not excluded
Cross-cutting
Dynamics of variability and bias in working memory
Tomić (Zagreb), Schneegans & Bays (Cambridge) · Psychological Review, 24 Sep 2026 Cross-cutting Encoding-Retrieval

Approach: Addresses a genuinely contradictory literature — does load accelerate decay during maintenance, and does recall drift toward canonical feature values? Six new experiments plus reanalysis of seven published ones under consistent analytic methods, explicitly separating response variability from stimulus-specific bias and modelling swap errors.

Finding: Recall variability grows with both delay and set size, and — the key result — the two do not act independently: the delay effect is amplified at higher set sizes. Systematic biases are reliably present but their amplitude changes with neither set size nor retention interval. That dissociation supports diffusion accounts (random error accumulating during maintenance) and is hard to reconcile with stable-attractor models, which predict drift toward canonical values that should grow with time.

Shaping Slow Manifolds in Equivariant Recurrent Neural Networks
Bernardo, Valente, Mastrogiuseppe, Ostojic (ENS Paris) · Neural Computation, 22 Sep 2026 Cross-cutting Schema-Episodic

Approach: Uses group representation theory to formalise the link between symmetries in recurrent connectivity and the geometry of the resulting fixed-point (continuous-attractor) manifolds. They reinterpret the classical ring attractor's connectivity as circular convolution, draw the parallel to feedforward CNNs, and generalise to arbitrary symmetry groups via group convolution, then reduce the resulting networks to low-rank models with the group Fourier transform.

Finding: A general principle — specify the symmetry group, and the attractor manifold's geometry follows — rather than the case-by-case construction the literature has relied on. For anyone building RNN models of hippocampal or head-direction-like representations, this gives a principled way to pick connectivity that yields a wanted manifold shape.

⚠ Theory paper; no fitting to neural population data, so empirical adequacy of the constructed manifolds is untested
