LLM-Memory
MoNe: Modular Neural Memory for Efficient Long Context Inference
Wonguk Cho, Kyubyung Chae, Tribhuvanesh Orekondy, Sunghyun Park, Hyoungwoo Park, Jeongho Kim et al. · arXiv:2608.17616, 2026-08-18 LLM-MemoryKV-Networks

Approach: Attaches a lightweight modular neural memory (fast-weight network with layer-local gradient updates) to a frozen pretrained Transformer; at inference the memory emits keys/values from query tokens alone, with no context re-read, giving O(N) cost.

Finding: Decouples inference cost from context length via a neural memory that generates K/V on demand — a concrete "KV generated by memory" design for long-context retention. Directly probes the KV-as-memory-store hypothesis.

⚠ Preprint (not peer-reviewed).
Proteus: Incremental Memory Activation for Long-Context Sequence Modeling
Reza Bayat, Ali Behrouz, Vahab Mirrokni, Aaron Courville · arXiv:2608.16844, 2026-08-17 LLM-MemoryKV-Networks

Approach: Proposes incremental memory activation for long-context models: instead of a static compressed state, later context can displace/refine early tokens' memory allocation to reduce interference.

Finding: Early tokens occupy too many degrees of freedom and "pollute" the memory state, increasing interference between stored and incoming context; incremental activation mitigates this. Interference in the memory state is exactly the phenomenon studied in KV/position memory — actionable.

⚠ Preprint (not peer-reviewed).
Learning how to Forget: Fine-tuning for Long-Context Sparse Attention
Matthias Seeger, Zeyu Zhang, Vihang Patil, Konstantinos Benidis, Sebastian Schelter · arXiv:2608.19920, 2026-08-20 LLM-MemoryKV-Networks

Approach: Fine-tunes transformers with sparse-attention KV-cache policies (any eviction rule) on a single A100, letting the model co-adapt with the policy rather than using exact attention.

Finding: Models trained with sparse/evicted KV attention can match or beat exact-attention baselines once they co-adapt to the policy — i.e., the network learns what to forget. Forgetting as a trainable memory-mechanism property; the inverse of lingering memory.

⚠ Preprint (not peer-reviewed).
Schema-Episodic
Infant learning forms lasting memory schemas that influence adult behavior
Benjamin Bessières, Emmanuel Prikas, Sebastian Goodwin-Groen, Leonardo Silenzi, Cristina M. Alberini · Neuron, 2026-08-19 Schema-EpisodicKV-Networks

Approach: Infant mice underwent episodic-like learning; the study traced whether this seeds an enduring schema and dissected the circuit via hippocampus-dependent consolidation assays and PFC manipulation during adult relearning of congruent vs. incongruent material.

Finding: Infantile episodic-like learning creates lasting memory schemas that facilitate adult relearning and the formation of new congruent memories. Schemas undergo hippocampus-dependent systems consolidation; critically, adult facilitation of congruent memories requires the PFC and top-down PFC→hippocampus projections — a direct mechanistic bridge to schema-binding hippocampal models.

Human hippocampal ripples prioritize model-based learning
Xiaoyu Zhou, Xiongfei Wang, Xiangyu Hu, Haiteng Wang, Jinbo Zhang, Qianqian Yu, Jiahua Xu, Zhibing Xiao, Li He, Yunzhe Liu · Neuron, 2026-08-19 Schema-Episodic

Approach: Human intracranial recordings during learning from sparse experience; analyzed hippocampal ripple events and their coordination with frontopolar cortex, testing generalization to related situations.

Finding: Hippocampal ripples coordinate with frontopolar cortex to convert sparse direct experience into model-based learning that generalizes. A human replay/ripple → schema-consolidation mechanism, consonant with the Bessières infant-schema results and with ripple-driven consolidation accounts.

Dissociation of Memory for Order and Memory for Items by Concurrent Cognitive Load in Rhesus Monkeys
Pankhuri Singhal, Victoria L. Templer, Robert R. Hampton · Hippocampus, 2026-08-21 Schema-EpisodicKV-Networks

Approach: Rhesus monkeys viewed 5 images in sequence and reported which appeared first; a concurrent cognitive load was inserted between study and test, with familiarity-based recognition tested as a control.

Finding: Concurrent load impaired order memory far more than recognition, indicating monkeys solved the task via working memory, not long-term episodic memory — so it is a weak model of episodic order memory. Clean dissociation between working-memory-dependent order coding and item/familiarity memory; bears on position/serial memory (the KV-network pillar).

Cancer Treatment and Memory in Breast Cancer Survivors: Differential Effects on Detailed Episodic and Gist-Like Memory Recall Over Time
Meenakshie Bradley-Garcia, Hamed Neveu Karimpour, Defne Oksit, Mitchell Lilley, Chloé Cateaux, Annick F. Tanguay, Melanie J. Sekeres · Hippocampus, 2026-08-14 Schema-Episodic

Approach: Breast cancer survivors (n=42) vs. non-cancer controls (n=41) viewed 40 short film clips; recall of central (gist) vs. peripheral (detailed episodic) details was tested immediately and after a 7-day delay.

Finding: BCS recalled fewer peripheral (detailed episodic) details, especially at immediate recall, while gist recall was preserved; no group difference in temporal sequencing or forgetting rate. Chemotherapy selectively impoverishes the richness of event representations while sparing the schematic core and temporal organization. Naturalistic film paradigm — directly relevant to Sherlock/PIEMAN-style event-memory analyses.

⚠ Observational; treatment not randomized. Naturalistic paradigm — flagged as priority.
KV-Networks
Aborted but Not Forgotten: KV-Cache Retention Breaks Rollback Consistency in Language Agents
Guijia Zhang, Harry Yang · arXiv:2608.15939, 2026-08-16 KV-NetworksLLM-Memory

Approach: Formalizes "rollback consistency" for stateful LLM agents: tests whether clearing a rejected branch from the transcript also clears the model's retained KV state.

Finding: KV-cache retention breaks rollback consistency — a cross-layer failure where a logical abort is incomplete because the model keeps attending to aborted context. A crisp demonstration that the KV cache is a persistent memory store whose retention is decoupled from the visible transcript. (A textbook exhibit for the lingering-memory story.)

⚠ Preprint (not peer-reviewed).
KV-Rescue: Recovering Reasoning Language Model KV Eviction Loss via Stepwise Interleaving
Minsoo Cheong, Woosang Lim, Vincent-Daniel Yun, Sungjoo Yoo · arXiv:2608.15797, 2026-08-16 KV-NetworksLLM-Memory

Approach: Characterizes loss from KV-cache eviction during long reasoning as an information gap (missing context) rather than a capability gap; proposes stepwise interleaving to recover evicted context.

Finding: Aggressive KV eviction causes runaway degeneration because the model decodes from a partial view of history; reframing the loss as missing-context (not capacity) motivates context recovery. Speaks directly to retention/forgetting in the KV store.

⚠ Preprint (not peer-reviewed).
Basin-Preserving Discretizations of Modern Hopfield Retrieval Dynamics: Energy Cells, Dissipation, and the Attention Limit
Francisco R. Villatoro · arXiv:2608.21304, 2026-08-21 KV-NetworksLLM-Memory

Approach: Studies time discretizations of modern Hopfield retrieval dynamics that preserve energy decay, equilibria, and basins of attraction; introduces "energy cells" (sublevel-set components containing one attractor).

Finding: Proves every finite energy cell below escape energy is preserved under the proposed discretization, linking Hopfield retrieval to the attention update as a difference-of-convex step. Connects associative memory (Hopfield) to attention — the mathematical backbone of KV/associative memory networks.

⚠ Preprint (single-author; not peer-reviewed).
KV Cache Compression Through the Lens of Transform Coding
Hannah Laus, Claudio Mayrink Verdun, Hao Wang, Flavio du Pin Calmon, Felix Krahmer · arXiv:2608.14191, 2026-08-14 KV-NetworksLLM-Memory

Approach: Frames KV-cache quantization as transform coding; proves (white-noise quantization model) the expected attention-aware distortion and derives an optimal compression objective that accounts for error propagation through attention rather than minimizing cache reconstruction error.

Finding: KV-cache compression should optimize attention-aware distortion, not raw cache MSE: errors propagate nonlinearly through softmax attention. A concrete mechanistic characterization of the KV cache as an information store — directly relevant to KV-memory capacity/retention claims.

⚠ Preprint (not peer-reviewed).
DeltaMomentum: A Key-Value based Anisotropic Momentum Update via Delta Rule
Euijin Hong, Guannan Qu · arXiv:2608.19491, 2026-08-19 KV-NetworksLLM-Memory

Approach: Builds direction-awareness into optimizer momentum via a key–value structured anisotropic update (delta rule), replacing the fixed-rate exponential moving average of past gradients.

Finding: Reframes optimizer momentum as a key-value memory that adapts per-direction learning rates to input anisotropy. A neat bridge between the delta rule (classical associative-memory update) and KV-structured memory — relevant to how KV networks store and retrieve associations.

⚠ Preprint (not peer-reviewed).
RecurrentGPT: Expressive Depth through Recurrent Modulation in Transformers
Amr Hegazy, Amr Alanwar, Mostafa Elhoushi · arXiv:2608.15062, 2026-08-15 KV-NetworksLLM-Memory

Approach: Introduces a recurrent-depth transformer: a fixed-depth prelude/coda wraps a recurrent core that re-reads its own hidden state, decoupling representational depth from parameter count.

Finding: Recurrent modulation enables expressive depth with constant memory footprint, trading layer-wise weights for a recurrent state. Positions recurrence as a memory mechanism alternative to the growing KV cache — relevant to the KV vs. recurrent memory trade-off in long-context models.

Differential Functional Connectivity Between Hippocampus and Prefrontal Cortex Is Associated With Heterogeneity in Open Field Exploration and Is Disrupted Following Maternal Immune Activation
Robert G. K. Munn, Desiree D. Dickerson, Amy R. Wolff, David K. Bilkey · Hippocampus, 2026-08-20 Encoding-Retrieval

Approach: Assayed hippocampus–prefrontal cortex functional connectivity and its relationship to individual differences in open-field exploration; tested disruption by maternal immune activation (MIA).

Finding: HPC–PFC functional connectivity tracks heterogeneity in exploratory behavior and is disrupted following MIA. Extends the PFC–hippocampus circuitry theme (cf. Bessières/Zhou) into a developmental/disruption model.
